## Learning Path

For a structured progression through these cybersecurity labs:

1. Start with **Thales Perspective Shift** and **Thales Perspective 2** to practice investigation and problem solving.
2. Explore **Tomcat Vault Recon 2** and the other Tomcat labs to develop web-server reconnaissance skills.
3. Study the **backup-script** labs to understand how automation and backup mechanisms can introduce weaknesses.
4. Move to **SUID Spark** and **SUID Sleuthing** for Linux privilege-escalation concepts.
5. Finish with **GTFOBins Shells to Root** to understand binary-based privilege-escalation risks.
6. Include **Tomcat Trail: Blue Team Detection** for a defensive perspective on suspicious activity.
